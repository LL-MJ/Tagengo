# Tagengo

日语学习库：单词、例句、语法相互关联，使用独立的私有 Git 仓库在两台 PC 之间同步。

## 本机使用

Windows 日常使用可直接双击项目根目录的 **启动学习库.cmd**，服务会在后台运行并自动打开浏览器。双击 **停止学习库.cmd** 可停止由启动器启动的服务。关闭网页不会停止后台服务。

也可以右键“启动学习库.cmd”，选择“发送到 → 桌面快捷方式”，以后从桌面打开。不要单独移动启动文件，它需要与项目文件放在一起。

安装 Node.js 24、Git，并确保当前 Git 凭据能够访问 `https://github.com/LL-MJ/Tagengo-data.git`。

```powershell
npm install
npm run local
```

浏览器打开 `http://localhost:3000/`。保存写入本地文件；右上角“同步”完成 Git 提交、拉取、合并、推送。

第一次启动自动克隆数据仓库到 `.local-data/Tagengo-data`。此目录已从代码仓库排除。GitHub 凭据由本机 Git 管理，不放在网页、学习记录或源码里。

详细步骤：[两台电脑配置与迁移](docs/SETUP.md)。[收录扩展安装](extension/README.md)。

## 同步原则

- 学习前同步一次，结束后再同步一次；保存操作本身不联网。
- 每条记录保存多个不可变 JSON 版本，按词条、例句、语法分类。通过父版本编号关联历史。
- 不同记录可以正常合并；同一记录并发修改保留双方，在页面显示冲突。Git 文件冲突中止合并，不强制覆盖远端。
- 删除保存为标记，不物理删除历史。断网或上传失败保留本地数据与提交，可再次同步。
- 首次打开只读本机文件，点击同步才获取其他电脑更新。
- 目前本地 Git 服务仅监听回环地址。手机与已部署的网页不会连接电脑上的数据目录；手机支持留待后续接入。
- 旧网页版仍可使用浏览器草稿；请导出 JSON 后在本地版导入。OneDrive 代码保留但不再作为默认入口。

## 开发与检查

```powershell
npm test
npx tsc --noEmit
npm run build
```

`npm run dev` 是普通网页开发预览，不启动 Git 服务；日常使用请运行 `npm run local`。
`npm run sync:data` 是不打开界面的同步命令，请在没有其他程序操作数据仓库时运行。

测试通过临时裸仓库和两份克隆验证并发编辑、删除、重复同步、失败重试、路径校验和本地接口访问控制；不会向真实仓库上传测试记录。

当前不含自动日语分析或模型 API 调用；读音、活用和语法可手填或使用 GPT 整理后的 JSON 导入。WebMCP 导入预览工具在支持的浏览器中注册，当前未做实际 WebMCP/浏览器 UI 测试。
