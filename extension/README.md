# 安装 ChatGPT 网页收录扩展

1. 解压扩展 ZIP 文件。
2. Edge 打开 edge://extensions；Chrome 打开 chrome://extensions。
3. 开启开发者模式，选择“加载解压缩的扩展”，选择含 manifest.json 的文件夹。
4. 点击扩展图标确认学习库网址。两台 PC 分别安装一次。
5. 在 https://chatgpt.com 中选中日语，右键“加入 Tagengo 日语学习库”。
6. 学习库中预览、补充释义和关联，再点击保存。

此版本只收录用户选中的内容，每次最多 12000 字符；不会自动扫描聊天。内容通过网址片段传递，片段不发送给网页服务器，但可能留在浏览器历史中。手机直接访问学习库，不需要扩展。扩展尚未上架浏览器商店。
