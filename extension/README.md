# 安装 ChatGPT 网页收录扩展

1. 启动学习库：在项目目录运行 `npm run local`。
2. 解压扩展 ZIP，或使用项目中的 `extension` 文件夹。
3. Edge 打开 `edge://extensions`；Chrome 打开 `chrome://extensions`。
4. 开启开发者模式，选择“加载解压缩的扩展”，选择含 `manifest.json` 的文件夹。
5. 点击扩展图标，将学习库网址设置为 `http://localhost:3000/`。已安装旧版本的电脑也要更新这个网址。
6. 在 ChatGPT 网页选中日语，右键“加入 Tagengo 日语学习库”。
7. 预览并补充释义和关联后保存，学习结束时点击“同步”。

两台 PC 分别安装。扩展只收录选中的内容，每次最多 12000 字符，不自动扫描聊天。内容通过网址片段传递，可能暂留在浏览器历史中。扩展尚未上架商店。手机暂未接入本地 Git 服务。
